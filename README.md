# Resilience of UK Freight Railway Network

## Overview

This repository contains the code and resources developed as part of my research work on the **resilience of freight rail transport in the United Kingdom**.

The project focuses on analysing the behaviour and resilience of the UK freight rail network under different conditions and potential disruptions.

The objective is to develop computational tools that can be used to analyse the network, identify potential vulnerabilities, and evaluate different resilience-related scenarios.

---

## Objectives

The main objectives of this project are:

* Analyse the structure of the UK freight railway network.
* Represent the railway network using computational methods.
* Identify important or vulnerable components of the network.
* Study the impact of potential disruptions.
* Develop tools to measure and analyse network resilience.
* Produce visualisations and results to support the analysis.

## Methodology

The general workflow of the project is:

```text
Data collection
      ↓
Data preprocessing
      ↓
Network construction
      ↓
Network analysis
      ↓
Disruption scenarios
      ↓
Resilience assessment
      ↓
Results & visualisation
```

The railway network is represented as a graph, where railway infrastructure components can be represented as **nodes** and **connections** between them as **edges**.

Different network metrics and disruption scenarios can then be used to investigate how the network responds to failures.

---

## Resilience Analysis

The project investigates how the freight railway network responds to disruptions affecting different parts of the infrastructure.

Scenarios include :

* Removal of individual edges (railway sections).

The resulting changes in network structure and performance can then be compared with the original network.

## Current Limitations

Several limitations apply to the current version of the project :

* The network representation may simplify certain aspects of the real railway infrastructure.
* Disruption scenarios represent theoretical rather than observed events.
* Results may depend on the assumptions and parameters used in each scenario.

These limitations will be considered when interpreting the results.
